A live map of how a big codebase fits together, for Claude Code and for you.

Nebulosity indexes every import in a repository ahead of time, so Claude Code can answer a question that follows imports through many files with one tool call. In tests, Claude Code with Nebulosity answered questions like this up to 4.4× faster, and up to 3.2× faster on Theia, a codebase Nebulosity was never adjusted for. It got every one of them right.

Questions that cross many files, answered in one call

In a large codebase, some questions take many steps to answer. To find out what a change to one file could affect, you need every file that imports it, then every file that imports those, and so on. Claude Code normally works this out with one search after another, and VS Code alone has about 15,000 files and over 140,000 imports.

Nebulosity reads every import once, ahead of time, and keeps the index current as you work. Claude Code then answers the whole question with a single tool call.

  • What could break if src/vs/base/common/event.ts changes?
  • How does main.ts end up loading terminal.ts?
  • Which entry points load this file?
  • Are there import cycles in src/vs/platform?

Claude Code uses Nebulosity's tools when they help, and can point things out on the Map while it explains.

See the same imports on the Map

The Map shows a codebase one folder at a time, with at most 50 boxes on screen and lines for what imports what. Click a box to see what it imports and what imports it, read its source, or search with Ctrl K. It keeps up as you save files, in your browser or in a VS Code panel beside your code.

The live demo is the Map on VS Code's own repository, all 15,040 files, with nothing to install.

Tested against Claude Code on its own

Claude Code got the same questions with and without Nebulosity, on three large open-source TypeScript codebases: VS Code, AFFiNE and Theia. Nebulosity was never adjusted for Theia, which makes it the fairest test of the three. Every answer was checked against a reference answer prepared without Nebulosity, across 378 runs.

On questions that follow imports through several files, Claude Code with Nebulosity was:

What could changing this file affect?4.3× faster, 2.1× cheapernot asked

Is this file part of an import cycle?2.3× faster, 1.5× cheaper1.5× faster, 1.1× cheaper

Each figure compares medians: 6 runs per setup on VS Code and AFFiNE together, 3 on Theia. With Nebulosity, Claude Code got all 42 of these answers fully right. Alone, it got 29 fully right and the other 13 partly right.

On simpler questions, such as listing the files that import a given file directly, Nebulosity made little difference, because one search already answers them. The questions were sorted into multi-step and simpler ones after the runs, the samples are small, and only TypeScript was tested.

Install

You'll need Node 24 or later and git, plus Claude Code 2.1.300 or later for the tools.

In your terminal

  1. Install the package:

    • npm install -g nebulosity

  2. From your repo's root folder:

    • nebulosity index .
      Reads the repo's files and imports. Free, and a minute or two for VS Code.
    • nebulosity map
      Opens the Map at http://localhost:3000. It keeps running, so use a second terminal for the next command.
    • nebulosity setup
      Connects Claude Code to this repo.

If something seems off, nebulosity doctor says what's missing. Every command and setting is in the guide.

In VS Code

  1. Install the package and index your repo, as in your terminal.

  2. Install the Nebulosity extension, or from a terminal:

    • code --install-extension andrewl746.nebulosity-vscode

  3. Run Nebulosity: Show Map from the Command Palette. The Map opens beside your code and follows the file you have open.

Free

Everything above works without an API key: the index, the Map, search and all seven of Claude Code's tools. Without a key, none of your code leaves your machine.

Seven languages

TypeScript and JavaScript through TypeScript's own compiler, plus Python, Go, Java, C# and Rust. The tests above were on TypeScript only.

AI summaries, if you want them

With an Anthropic API key, nebulosity summarize . writes a short summary of every file and folder. It sends your code to Anthropic, costs about $1 per 1,000 files, and shows an estimate and waits for a yes before spending anything.
