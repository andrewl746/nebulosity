**Goal:** Ship v1's demo half. Tune search against its own query set, then freeze the engine. Run the evaluation of Claude Code with and without Nebulosity's MCP server on VS Code at `cc3fec88` and publish it, losses included (S7). **Architecture:** Three tracks over the existing engine.
- **Search** (`lib/engine/`): the pure ranking code moves into a browser-safe module, `rank.ts`. Search gains a fifth list, files named like the query or declaring what it names. Test targets are damped, and a file's snippet prefers a declaration over its imports listing. One engine serves the Map's palette, the MCP `search` tool and, through `rank.ts`, the static demo.
- **Static demo** (`lib/demo/`, `scripts/export-demo.ts`, `app/map/staticApi.ts`): an exporter writes every level page, every describe answer (bundled per folder) and a search index as JSON, with the repo's absolute root replaced by its name. A build flag swaps `app/map/api.ts`'s transport for one that reads those files, and turns off what needs a server. `scripts/build-demo.ts` builds the static site, copies the data in, refuses any file holding a machine path, and checks the host's limits.
- **Evaluation** (`scripts/eval/`, `eval/`): a ground-truth scanner that shares no code with the indexer, a runner that drives `claude -p` in two arms differing only in the MCP config, a validator that refuses a run whose setup isn't what was agreed, mechanical scoring for lists and chains, blind rubric grading for big-picture answers, and `docs/EVAL_RESULTS.md`.

**Tech Stack:** TypeScript 5, Node 24, Next.js 16 (bumped from 16.2.10 to clear the critical advisory; `output: "export"` for the demo), React 19, better-sqlite3 + Drizzle (WAL), Vitest 4, tsx. Claude Code 2.1.296 (`claude -p`, stream-json) for the eval, on the owner's Max subscription. No new runtime dependency.

**Spec:** `docs/PIVOT_SPEC.md` §2 (S7, S8), §7 ("Static demo mode"), §9 (the evaluation), §12–§14. Decisions ADR-027 (search, with its amendments), ADR-043 (what the eval must show, losses included), ADR-044 → ADR-048 (the MCP server the eval runs against). `docs/API_CONTRACTS.md` §10 and §17; `docs/RAG_PIPELINE.md` §6; `docs/BENCHMARKS.md` Summary Benchmark #1, MCP Benchmark #1, MCP Smoke Test #1. Ranked by how many files import it, so VS Code's real `lifecycle.ts` beats Copilot's copy.

- **One engine, three surfaces:**
  - the Map's palette calls `GET /api/search`, which calls the engine, so it follows by itself (folders first, then files, as now);
  - the MCP `search` tool calls the same engine;
  - the static demo uses the same ranking code (`rank.ts`), minus the code and meaning lists, which need the database and the model (D6).

**Alternatives:**
- (a) Tune the RRF weights only: one knob, but it can't put `lifecycle.ts` first when no list ranks it near the top.
- (b) Learning-to-rank over the tuning set: overfits 32 queries and is hard to explain.

```ts
/**
 * Scoring for Search Benchmark #2 (docs/plans/2026-10-13-v1-5-ship.md, D5): each query of the tuning set lists the
 * targets a person would expect, by hand, and a ranking is judged by where the first of them lands.
 */
export type Expectation = { query: string; group: "names" | "features" | "questions"; expect: string[] };
export type RankedHit = { path: string; kind: "file" | "folder" };
export type Metrics = { queries: number; hitAt1: number; hitAt3: number; hitAt5: number; mrr: number };

/** A folder expectation ends in "/" and takes the folder or anything inside it; a file expectation takes only that file. */
export function accepts(expected: string, hit: RankedHit): boolean {
    if (!expected.endsWith("/")) return hit.kind === "file" && hit.path === expected;
    const folder = expected.slice(0, -1);
    return hit.path === folder || hit.path.startsWith(`${folder}/`);
}

/** The 1-based rank of the first hit any expectation takes, or null when none does. */
export function firstAcceptable(hits: readonly RankedHit[], expect: readonly string[]): number | null {
    const at = hits.findIndex((hit) => expect.some((e) => accepts(e, hit)));
    return at === -1 ? null : at + 1;
}

/** hit@k: the share of queries whose first acceptable hit is in the top k. MRR: the mean of 1/rank, 0 past rank 10. */
export function metrics(ranks: readonly (number | null)[]): Metrics {
    const within = (k: number): number => ranks.filter((r) => r !== null && r <= k).length / ranks.length;
    const mrr = ranks.reduce<number>((sum, r) => sum + (r !== null && r <= 10 ? 1 / r : 0), 0) / ranks.length;
    return { queries: ranks.length, hitAt1: within(1), hitAt3: within(3), hitAt5: within(5), mrr };
}
```

```ts
/**
 * The ranking half of search (RAG_PIPELINE.md §6): query words, names, and Reciprocal Rank Fusion. Pure, and safe for
 * the browser: it imports nothing that opens a database or reads a disk, so the static demo ranks with the same code
 * the server does (ADR-049). The lists themselves come from search.ts (the server) or staticSearch.ts (the demo).
 */

/**
 * The words a query searches for: its words, lowercased, without stopwords and single letters, each identifier
 * followed by its parts ("openEditor" adds "open" and "editor").
 */
export function queryTerms(query: string): string[] {
    const terms: string[] = [];
    const add = (term: string): void => {
        if (term.length > 1 && !STOPWORDS.has(term) && !terms.includes(term)) terms.push(term);
    };
    for (const token of query.match(/[\p{L}\p{N}_]+/gu) ?? []){
        add(token.toLowerCase());
        for (const part of splitIdentifier(token).split(" ")) add(part);
    }
    return terms;
}

/**
 * Turns free text into a safe FTS5 query. Every word is quoted, so nothing the user types is read as FTS5 syntax, and
 * the words are ORed: bm25 ranks documents matching more and rarer words higher. Null when nothing searchable is left.
 */
export function toFtsQuery(query: string): string | null {
    const terms = queryTerms(query);
    return terms.length === 0 ? null : terms.map((t) => `"${t}"`).join(" OR ");
}
```

```ts
/** A file for the file-name list: its path and how many files import it (its importance, ADR-010). */
export type FileFact = { path: string; importedBy: number };
/** An exported top-level declaration and the file declaring it. */
export type Declared = { name: string; path: string };

/** A file's name as a word: no folder, no extension, no .test/.spec marker ("lifecycle" for lifecycle.ts). */
export function fileStem(filePath: string): string {
    const base = filePath.slice(filePath.lastIndexOf("/") + 1);
    return base.replace(/\.(test|spec)(?=\.[cm]?[jt]sx?$)/, "").replace(/\.[cm]?[jt]sx?$/, "");
}

/**
 * Files named like the query or declaring what it names, most imported first, then by path (ADR-052). A file counts
 * when its name is a query word, or that word plus an ending of up to 3 letters with both 4+ letters long (nameMatch's
 * first tier: "lifecycle" finds lifecycle.ts, "debugger" finds debug.ts), or when it exports a top-level declaration
 * named exactly like a query word ("registerSingleton" finds the file defining it). Partial matches stay with the
 * code list: thousands of files contain a common word. Importance breaks ties, so VS Code's own lifecycle.ts comes
 * before an extension's copy of it.
 */
export function rankFileNames(files: readonly FileFact[], declared: readonly Declared[], query: string): string[] {
    const words = nameWords(query);
    if (words.length === 0) return [];
    const exact = new Set(words);
    const found = new Set<string>();
    for (const file of files){
        const stem = fileStem(file.path).toLowerCase();
        if (words.some((w) => nameMatch(stem, w) === 0)) found.add(file.path);
    }
    for (const d of declared) if (exact.has(d.name.toLowerCase())) found.add(d.path);

    const importedBy = new Map(files.map((f) => [f.path, f.importedBy]));
    return [...found].sort((a, b) => (importedBy.get(b) ?? 0) - (importedBy.get(a) ?? 0) || (a < b ? -1 : a > b ? 1 : 0));
}
```

```markdown
## ADR-052 — Search finds files by their names and declarations, damps tests, and shows declarations before imports (‹today›) — amends ADR-027

**Context:** ADR-027 fused code keywords, summary keywords and meaning; V1.3.1 added folder names. V1.2 and V1.3 left ranking cases for V1.5's query set: "lifecycle" ranked `src/vs/base/common/lifecycle.ts` 6th then, and by V1.5's planning probe it was outside the top 8, as it was for "Disposable", though it's the most imported file in VS Code. "registerSingleton" ranked its own file 2nd; "terminal" put a smoke-test folder 2nd; a file's snippet was often its imports listing with a `File: <path> Imports:` header.
**Decision:**
- **A fifth list, file names**, weighted 2 like folder names: a file whose name is a query word (or that word plus an ending of up to 3 letters, both 4+ letters), or that exports a top-level declaration named exactly like one. Most imported first, then by path.
- **Tests damped:** a test file or a test-only folder keeps half its fused score unless the query asks for tests (test, tests, testing, spec, specs, smoke, e2e, fixture, fixtures, mock, mocks).
- **Snippets:** a file shows its best-matching declaration when one matched; an imports listing loses its header and reads "imports and exports", without a line range.
- **The ranking core** (`lib/engine/rank.ts`) is pure and browser-safe, so the static demo ranks with the same code (ADR-049).
**Measured** (Search Benchmark #2, 32 queries set by hand, none naming an eval target): hit@5 ‹before› → ‹after›, MRR ‹before› → ‹after›; names hit@1 ‹…› → ‹…›; plain-language questions hit@5 ‹…› → ‹…›; V1.2's five checks all in the top 5.
**Alternatives:** (a) Re-weight the existing lists: no list ranked `lifecycle.ts` near the top, so no weight could. (b) Partial file-name matches (prefix, contains): thousands of files contain a common word, and the code list already reaches them. /** A test target's share of its fused score when the query isn't about tests (ADR-052). */
```
```ts
export const TEST_DAMPING = 0.5;

export function wantsTests(query: string): boolean {
    return nameWords(query).some((w) => TEST_WORDS.has(w));
}

/** Folders with at least one file below them and no file that isn't a test, the root never counted (like summaries' rule). */
export function testOnlyFolders(files: readonly { path: string; isTest: boolean }[]): Set<string> {
    const hasTest = new Set<string>();
    const hasOther = new Set<string>();
    for (const file of files){
        for (let at = file.path.lastIndexOf("/"); at > 0; at = file.path.lastIndexOf("/", at - 1)){
            (file.isTest ? hasTest : hasOther).add(file.path.slice(0, at));
        }
    }
    return new Set([...hasTest].filter((folder) => !hasOther.has(folder)));
}

/**
 * Halves the fused score of test files and test-only folders unless the query asks for tests, then sorts again (ties by
 * key): searching "terminal" shouldn't lead with a smoke-test folder, and "terminal smoke test" still finds it.
 */
export function dampTests<T extends { key: string; score: number }>(fused: readonly T[], isTest: (key: string) => boolean, query: string): T[] {
    if (wantsTests(query)) return [...fused];
    return fused
        .map((f) => (isTest(f.key) ? { ...f, score: f.score * TEST_DAMPING } : f))
        .sort((a, b) => b.score - a.score || (a.key < b.key ? -1 : a.key > b.key ? 1 : 0));
}
```

```ts
import fs from "fs";
import path from "path";

/** A file in a folder about to be published that holds a path of this machine, or the owner's email. */
export type Leak = { file: string; needle: string };

/**
 * Every way an absolute folder can show up in a file, lowercased for a case-blind match: forward slashes, backslashes,
 * backslashes as JSON escapes them, URL-encoded either way, and Git Bash's /c/… for a drive path. A folder shallower
 * than two segments is refused: "C:/" would match every Windows path (D7).
 */
export function spellings(folder: string): string[] {
    const forward = folder.replace(/\\/g, "/").replace(/\/+$/, "");
    if (forward.split("/").filter(Boolean).length < 2) throw new Error(`"${folder}" is too shallow to scan for: it would match everything`);
    const back = forward.replace(/\//g, "\\");
    const forms = [forward, back, back.replace(/\\/g, "\\\\"), encodeURIComponent(forward), encodeURIComponent(back)];
    const drive = /^([a-zA-Z]):\//.exec(forward);
    if (drive) forms.push(`/${drive[1]}/${forward.slice(3)}`);
    return [...new Set(forms.map((f) => f.toLowerCase()))];
}

/** The needles for some folders and an email, longest first, so a report names the most specific match. */
export function leakNeedles(input: { folders: readonly string[]; email?: string | null }): string[] {
    const needles = new Set(input.folders.flatMap((folder) => spellings(folder)));
    if (input.email) needles.add(input.email.toLowerCase());
    return [...needles].sort((a, b) => b.length - a.length || (a < b ? -1 : a > b ? 1 : 0));
}

/** The first needle a text holds, ignoring case, or null. */
export function findLeak(text: string, needles: readonly string[]): string | null {
    const lower = text.toLowerCase();
    return needles.find((needle) => lower.includes(needle)) ?? null;
}

/**
 * Every file under a folder that holds a needle, by path relative to the folder. Each file is read as UTF-8 and as
 * latin1, so a needle is found in text with any non-ASCII name and in binary files alike.
 */
export function scanForLeaks(dir: string, needles: readonly string[]): Leak[] {
    const leaks: Leak[] = [];
    const walk = (folder: string): void => {
        for (const entry of fs.readdirSync(folder, { withFileTypes: true })){
            const full = path.join(folder, entry.name);
            if (entry.isDirectory()){
                walk(full);
                continue;
            }
            const bytes = fs.readFileSync(full);
            const needle = findLeak(bytes.toString("utf8"), needles) ?? findLeak(bytes.toString("latin1"), needles);
            if (needle !== null) leaks.push({ file: path.relative(dir, full).replace(/\\/g, "/"), needle });
        }
    };
    walk(dir);
    return leaks.sort((a, b) => (a.file < b.file ? -1 : a.file > b.file ? 1 : 0));
}
```

```ts
import fs from "fs";
import os from "os";
import path from "path";
import {
    DEMO_FORMAT_VERSION, type DemoDescribeBundle, type DemoManifest, type DemoPageIndex, type DemoSearchIndex, type LevelResponse,
} from "../contracts";
import { getDb } from "../db/client";
import { loadExportedNames } from "../db/store/search";
import { loadIndexedHead, requireRepository } from "../db/store/structure";
import { loadFileFacts, loadFolderFacts, loadSummaries } from "../db/store/summaries";
import { readIndexVersion } from "../db/store/version";
import { describe } from "../engine/describe";
import { readRepoRemote } from "../engine/git-remote";
import { level } from "../engine/level";
import { readIndexStatus } from "../engine/status";
import { nebulosityHome } from "../home";
import { dirOf, repoKey } from "../index/paths";
import { leakNeedles, scanForLeaks, type Leak } from "./privacy";

export type DemoExportOptions = {
    /** The name the demo shows for the repo, in place of its root; its folder's name by default. */
    publicName?: string;
    now?: Date;
    /** Also scanned for, with the folders (the CLI passes git's user.email). */
    email?: string | null;
};
export type DemoExportReport = {
    folders: number; levelFiles: number; bundles: number; pageIndexes: number;
    files: number; bytes: number; indexVersion: number; leaks: Leak[];
};

/** The output folder holds something that isn't an earlier export, so it's left alone. */
export class ExportRefusedError extends Error {
    constructor(dir: string){
        super(`${dir} isn't empty and isn't an earlier demo export (no manifest.json), so nothing was written. Pick an empty folder.`);
        this.name = "ExportRefusedError";
    }
}

/** The index moved while the export read it (the Map's worker wrote), so the files may disagree with each other. */
export class IndexChangedError extends Error {
    constructor(){
        super("The index changed during the export (the Map's background worker wrote). Run the export again.");
        this.name = "IndexChangedError";
    }
}

/** Written first and removed last, so an export that died half-way is recognised and replaced next time. */
const IN_PROGRESS = "EXPORTING";

/** Empties an earlier export (or an interrupted one); refuses anything else. */
function prepare(outDir: string): void {
    if (fs.existsSync(outDir) && fs.readdirSync(outDir).length > 0){
        const earlier = fs.existsSync(path.join(outDir, "manifest.json")) || fs.existsSync(path.join(outDir, IN_PROGRESS));
        if (!earlier) throw new ExportRefusedError(outDir);
        fs.rmSync(outDir, { recursive: true, force: true });
    }
    fs.mkdirSync(outDir, { recursive: true });
    fs.writeFileSync(path.join(outDir, IN_PROGRESS), "");
}

/** A page's own boxes (portals stand for other pages, so they're left out). */
const boxesOf = (page: LevelResponse): string[] => page.nodes.filter((n) => n.kind !== "portal").map((n) => n.path);

/**
 * Writes the static demo of an indexed repo (ADR-049, API_CONTRACTS.md §18): every page of every folder's level, every
 * describe answer bundled per folder, a page index per paged folder, a search index and a manifest. Every answer names
 * the repo by its public name instead of its absolute root, and the finished folder is scanned for any spelling of
 * the repo's root, the Nebulosity folder or the home folder (and the email, when given). Read only on the database.
 */
export function exportDemo(repoRoot: string, outDir: string, options: DemoExportOptions = {}): DemoExportReport {
    const root = path.resolve(repoRoot);
    const db = getDb();
    const repoId = requireRepository(db, repoKey(root));
    const status = readIndexStatus(root);
    if (status === null) throw new Error(`${root} has no index status; run npm run index -- ${root} first.`);
    const version = readIndexVersion(db, repoId);
    const publicName = options.publicName ?? path.basename(root);
    const summariesOff = status.stages.summaries.state === "off";
    prepare(outDir);

    let files = 0;
    let bytes = 0;
    const write = (rel: string, value: unknown): void => {
        const file = path.join(outDir, rel);
        fs.mkdirSync(path.dirname(file), { recursive: true });
        const text = JSON.stringify(value);
        fs.writeFileSync(file, text);
        files++;
        bytes += Buffer.byteLength(text);
    };
    const named = <T extends { repo: string }>(answer: T): T => ({ ...answer, repo: publicName });

    // levels, page by page; a paged folder also gets the index of its pages' boxes
    const folders = loadFolderFacts(db, repoId);
    const paths = folders.map((f) => f.path);
    const pages: Record<string, number> = {};
    let levelFiles = 0;
    let pageIndexes = 0;
    paths.forEach((folder, id) => {
        const first = level(root, folder, { summariesOff });
        write(`level/${id}-0.json`, named(first));
        levelFiles++;
        if (first.pageCount <= 1) return;
        pages[String(id)] = first.pageCount;
        const boxes = [boxesOf(first)];
        for (let page = 1; page < first.pageCount; page++){
            const next = level(root, folder, { summariesOff, page });
            write(`level/${id}-${page}.json`, named(next));
            levelFiles++;
            boxes.push(boxesOf(next));
        }
        write(`pages/${id}.json`, { boxes } satisfies DemoPageIndex);
        pageIndexes++;
    });

    // describe answers, one bundle per folder: the folder's own, then each file directly inside it, in path order
    const ids = new Map(paths.map((p, i) => [p, i]));
    const facts = loadFileFacts(db, repoId);
    const bundles: DemoDescribeBundle[] = paths.map((folder) => ({ [folder]: named(describe(root, folder, { summariesOff })) }));
    for (const file of facts) bundles[ids.get(dirOf(file.path))!][file.path] = named(describe(root, file.path, { summariesOff }));
    bundles.forEach((bundle, id) => write(`describe/${id}.json`, bundle));

    // what the demo's search ranks (staticSearch.ts)
    const position = new Map(facts.map((f, i) => [f.path, i]));
    write("search.json", {
        summaries: loadSummaries(db, repoId)
            .filter((s) => s.kind !== "repo" && s.tagline)
            .map((s): [number, string, string, string] => [s.kind === "folder" ? 1 : 0, s.path, s.tagline!, s.summary ?? ""]),
        folders: folders.filter((f) => f.path !== "").map((f): [string, number] => [f.path, f.fileCount]),
        files: facts.map((f): [string, number, number] => [f.path, f.importedBy, f.isTest ? 1 : 0]),
        declarations: loadExportedNames(db, repoId).map((d): [string, number] => [d.name, position.get(d.path)!]),
    } satisfies DemoSearchIndex);

    // the indexed repo's license travels with data derived from its code
    const license = ["LICENSE.txt", "LICENSE", "LICENSE.md"].map((n) => path.join(root, n)).find((p) => fs.existsSync(p));
    if (license){
        fs.copyFileSync(license, path.join(outDir, "SOURCE-LICENSE.txt"));
        files++;
        bytes += fs.statSync(license).size;
    }

    if (readIndexVersion(db, repoId) !== version) throw new IndexChangedError();
    const remote = readRepoRemote(root);
    write("manifest.json", {
        format: DEMO_FORMAT_VERSION,
        repo: publicName,
        ...(remote ? { remote } : {}),
        commit: loadIndexedHead(db, repoId),
        exportedAt: (options.now ?? new Date()).toISOString(),
        status: { ...status, repo: publicName },
        folders: paths,
        pages,
    } satisfies DemoManifest);
    fs.rmSync(path.join(outDir, IN_PROGRESS));

    const leaks = scanForLeaks(outDir, leakNeedles({ folders: [root, nebulosityHome(), os.homedir()], email: options.email }));
    return { folders: paths.length, levelFiles, bundles: bundles.length, pageIndexes, files, bytes, indexVersion: version, leaks };
}
```

```ts
import type { DemoSearchIndex, SearchHit, SearchResult } from "../contracts";
import { splitIdentifier } from "../index/identifiers";
import { dampTests, dropRepoName, fuseRankings, LIST_DEPTH, queryTerms, rankFileNames, rankFolderNames, testOnlyFolders, type Declared, type FileFact } from "./rank";

/**
 * Search in the static demo (ADR-049), with no server: BM25 over the exported summaries, plus folder names and file
 * names, fused by the server's own ranking code (rank.ts). There's no code-text list (its index is hundreds of MB)
 * and no meaning list (it needs the model), and every result says so.
 */
export const STATIC_NOTE = "This demo searches names and summaries; the app also searches code and meaning.";

/** BM25's constants, as FTS5 sets them. */
const K1 = 1.2;
const B = 0.75;
/** Field weights for [path, tagline, summary], as the server's summary index ranks them (RAG_PIPELINE.md §6). */
const WEIGHTS = [1, 4, 2] as const;
/** A query word this long or longer also matches words it begins ("render" finds "rendered"); shorter ones match whole words. */
const MIN_PREFIX = 3;

/** A text's words: lowercased, each identifier followed by its parts, the way queryTerms splits a query. */
export function tokenize(text: string): string[] {
    const tokens: string[] = [];
    for (const word of text.match(/[\p{L}\p{N}_]+/gu) ?? []){
        tokens.push(word.toLowerCase());
        const parts = splitIdentifier(word).split(" ");
        if (parts.length > 1) tokens.push(...parts);
    }
    return tokens;
}

type Doc = { key: string; tagline: string; summary: string; counts: Map<string, number>[]; lengths: number[] };
export type StaticSearch = {
    docs: Doc[];
    /** Every word in any field, sorted, for prefix lookups. */
    vocabulary: string[];
    /** Which documents hold each word. */
    postings: Map<string, number[]>;
    averages: number[];
    folders: { path: string; name: string; fileCount: number }[];
    files: FileFact[];
    declared: Declared[];
    tests: Set<string>;
};

export function buildStaticSearch(index: DemoSearchIndex): StaticSearch {
    const postings = new Map<string, number[]>();
    const docs = index.summaries.map(([kind, docPath, tagline, summary], d): Doc => {
        const fields = [docPath, tagline, summary].map(tokenize);
        const counts = fields.map((tokens) => {
            const count = new Map<string, number>();
            for (const token of tokens) count.set(token, (count.get(token) ?? 0) + 1);
            return count;
        });
        for (const word of new Set(fields.flat())) postings.set(word, [...(postings.get(word) ?? []), d]);
        return { key: `${kind === 1 ? "folder" : "file"}:${docPath}`, tagline, summary, counts, lengths: fields.map((f) => f.length) };
    });
    const averages = WEIGHTS.map((_, f) => docs.reduce((sum, doc) => sum + doc.lengths[f], 0) / Math.max(1, docs.length) || 1);
    const files = index.files.map(([filePath, importedBy]) => ({ path: filePath, importedBy }));
    const testFolders = testOnlyFolders(index.files.map(([filePath, , isTest]) => ({ path: filePath, isTest: isTest === 1 })));
    return {
        docs,
        vocabulary: [...postings.keys()].sort(),
        postings,
        averages,
        folders: index.folders.map(([folderPath, fileCount]) => ({ path: folderPath, name: folderPath.slice(folderPath.lastIndexOf("/") + 1), fileCount })),
        files,
        declared: index.declarations.map(([name, file]) => ({ name, path: index.files[file][0] })),
        tests: new Set([
            ...index.files.filter(([, , isTest]) => isTest === 1).map(([filePath]) => `file:${filePath}`),
            ...[...testFolders].map((folder) => `folder:${folder}`),
        ]),
    };
}

/** The vocabulary's words a query term matches: itself, plus every word it begins when it's 3+ letters long. */
function matching(vocabulary: readonly string[], term: string): string[] {
    if (term.length < MIN_PREFIX) return vocabulary.includes(term) ? [term] : [];
    let low = 0;
    let high = vocabulary.length;
    while (low < high){
        const mid = (low + high) >> 1;
        if (vocabulary[mid] < term) low = mid + 1;
        else high = mid;
    }
    const found: string[] = [];
    for (let i = low; i < vocabulary.length && vocabulary[i].startsWith(term); i++) found.push(vocabulary[i]);
    return found;
}

/** BM25 per document key, over the terms given; a term matching several words counts all their occurrences. */
export function bm25Scores(s: StaticSearch, terms: readonly string[]): Map<string, number> {
    const scores = new Map<string, number>();
    for (const term of terms){
        const words = matching(s.vocabulary, term);
        const holding = new Set(words.flatMap((w) => s.postings.get(w) ?? []));
        if (holding.size === 0) continue;
        const idf = Math.log(1 + (s.docs.length - holding.size + 0.5) / (holding.size + 0.5));
        for (const d of holding){
            const doc = s.docs[d];
            let sum = 0;
            WEIGHTS.forEach((weight, f) => {
                const tf = words.reduce((n, w) => n + (doc.counts[f].get(w) ?? 0), 0);
                if (tf > 0) sum += (weight * tf * (K1 + 1)) / (tf + K1 * (1 - B + (B * doc.lengths[f]) / s.averages[f]));
            });
            scores.set(doc.key, (scores.get(doc.key) ?? 0) + idf * sum);
        }
    }
    return scores;
}

export function bm25Rank(s: StaticSearch, terms: readonly string[]): string[] {
    return [...bm25Scores(s, terms).entries()]
        .sort((a, b) => b[1] - a[1] || (a[0] < b[0] ? -1 : a[0] > b[0] ? 1 : 0))
        .map(([key]) => key);
}

export function searchStatic(s: StaticSearch, typed: string, options: { limit?: number; repoName: string }): SearchResult {
    const query = dropRepoName(typed, options.repoName);
    const summary = bm25Rank(s, queryTerms(query)).slice(0, LIST_DEPTH);
    const name = rankFolderNames(s.folders, query).slice(0, LIST_DEPTH).map((p) => `folder:${p}`);
    const file = rankFileNames(s.files, s.declared, query).slice(0, LIST_DEPTH).map((p) => `file:${p}`);
    const texts = new Map(s.docs.map((doc) => [doc.key, doc]));

    const hits: SearchHit[] = dampTests(fuseRankings({ summary, name, file }), (key) => s.tests.has(key), query)
        .slice(0, options.limit ?? 10)
        .map(({ key, score, matchedBy }) => {
            const kind = key.startsWith("folder:") ? "folder" : "file";
            const text = texts.get(key);
            return { path: key.slice(kind.length + 1), kind, score, matchedBy, ...(text ? { tagline: text.tagline, summary: text.summary } : {}) };
        });
    return { query: typed, hits, lists: { code: 0, summary: summary.length, vector: 0, name: name.length, file: file.length }, note: STATIC_NOTE };
}
```

```ts
import type { DemoManifest, DemoPageIndex } from "@/lib/contracts";
import { parentOf } from "./paths";

/**
 * Pure lookups over the static demo's manifest (API_CONTRACTS.md §18): folders are named by id in the file paths, so a
 * folder called "my docs #1" never has to survive a URL.
 */
export type DemoIndex = { manifest: DemoManifest; ids: Map<string, number> };

export const indexManifest = (manifest: DemoManifest): DemoIndex => ({ manifest, ids: new Map(manifest.folders.map((p, i) => [p, i])) });
export const levelFile = (id: number, page: number): string => `level/${id}-${page}.json`;
export const describeFile = (id: number): string => `describe/${id}.json`;
export const pagesFile = (id: number): string => `pages/${id}.json`;
export const pageCountOf = (index: DemoIndex, id: number): number => index.manifest.pages[String(id)] ?? 1;
/** A page past the last is the last, as the server answers (API_CONTRACTS.md §11). */
export const clampPage = (page: number, pageCount: number): number => Math.min(Math.max(0, Math.floor(page)), pageCount - 1);

/** The child of `folder` on the way to `target` (the target itself when it's directly inside), or null when it isn't inside. */
export function boxToward(folder: string, target: string): string | null {
    const prefix = folder === "" ? "" : `${folder}/`;
    if (target === folder || !target.startsWith(prefix)) return null;
    const rest = target.slice(prefix.length);
    const slash = rest.indexOf("/");
    return prefix + (slash === -1 ? rest : rest.slice(0, slash));
}

export function pageHolding(pages: DemoPageIndex, box: string): number | null {
    const at = pages.boxes.findIndex((boxes) => boxes.includes(box));
    return at === -1 ? null : at;
}

/** The bundle holding a path's describe answer: a folder's own, or its folder's for a file; null when neither is indexed. */
export function bundleIdFor(index: DemoIndex, targetPath: string): number | null {
    return index.ids.get(targetPath) ?? index.ids.get(parentOf(targetPath)) ?? null;
}
```

```ts
import {
    DEMO_FORMAT_VERSION, type DemoDescribeBundle, type DemoManifest, type DemoPageIndex, type DemoSearchIndex,
    type DescribeResponse, type IndexEventMap, type LevelResponse, type RepoList, type SourceResponse, type SummarizeResponse,
} from "@/lib/contracts";
import { buildStaticSearch, searchStatic, type StaticSearch } from "@/lib/engine/staticSearch";
import type { GitHubSource, MapApi } from "./api";
import { ApiError } from "./apiError";
import { boxToward, bundleIdFor, clampPage, describeFile, indexManifest, levelFile, pageCountOf, pageHolding, pagesFile, type DemoIndex } from "./demoData";

/** Describe bundles kept in memory; a visitor rarely opens more folders than this. */
const MAX_BUNDLES = 100;
const notIndexed = (targetPath: string): ApiError => new ApiError(404, "NOT_FOUND", `Nothing is indexed at "${targetPath}".`);
const notInDemo = (what: string): ApiError => new ApiError(404, "NOT_FOUND", `${what} isn't part of the static demo; it needs Nebulosity running on your machine.`);

/**
 * The Map's transport in the static demo (ADR-049): the same calls as the server's API, answered from the exported
 * files (API_CONTRACTS.md §18). What needs a server (summarize, re-index, switching repos, the source viewer) refuses.
 * Shared files (the manifest, bundles, the search index) are fetched once and kept, without a caller's abort signal,
 * so one caller giving up doesn't fail the next.
 */
export function createStaticApi(base: string = "/demo/", fetcher: typeof fetch = (...args) => fetch(...args)): MapApi & { github(): Promise<GitHubSource | null> } {
    let manifest: Promise<DemoIndex> | null = null;
    let searchIndex: Promise<StaticSearch> | null = null;
    const bundles = new Map<number, Promise<DemoDescribeBundle>>();

    async function file<T>(rel: string, signal?: AbortSignal): Promise<T> {
        let response: Response;
        try{
            response = await fetcher(base + rel, { signal });
        } catch (err){
            if (err instanceof DOMException && err.name === "AbortError") throw err;
            throw new ApiError(0, "NETWORK", "The demo's data didn't load. Check the connection and reload.");
        }
        if (response.status === 404) throw new ApiError(404, "NOT_FOUND", `The demo has no ${rel}.`);
        if (!response.ok) throw new ApiError(response.status, "INTERNAL", `The demo's ${rel} didn't load (HTTP ${response.status}).`);
        return (await response.json()) as T;
    }

    const index = (): Promise<DemoIndex> => (manifest ??= file<DemoManifest>("manifest.json").then((m) => {
        if (m.format !== DEMO_FORMAT_VERSION){
            throw new ApiError(500, "INTERNAL", `This demo's data is format ${m.format}, and this page reads format ${DEMO_FORMAT_VERSION}. Reload the page.`);
        }
        return indexManifest(m);
    }).catch((err: unknown) => {
        manifest = null;
        throw err;
    }));

    return {
        async level(folderPath: string, page: number = 0, signal?: AbortSignal, focus?: string): Promise<LevelResponse> {
            const at = await index();
            const id = at.ids.get(folderPath);
            if (id === undefined) throw notIndexed(folderPath);
            const count = pageCountOf(at, id);
            let wanted = clampPage(page, count);
            // the page holding the focus wins, as on the server; a focus outside this folder is ignored
            const box = focus === undefined ? null : boxToward(folderPath, focus);
            if (box !== null && count > 1) wanted = pageHolding(await file<DemoPageIndex>(pagesFile(id), signal), box) ?? wanted;
            return file<LevelResponse>(levelFile(id, wanted), signal);
        },
        async describe(targetPath: string): Promise<DescribeResponse> {
            const id = bundleIdFor(await index(), targetPath);
            if (id === null) throw notIndexed(targetPath);
            let bundle = bundles.get(id);
            if (bundle === undefined){
                bundle = file<DemoDescribeBundle>(describeFile(id));
                bundles.set(id, bundle);
                bundle.catch(() => bundles.delete(id));
                if (bundles.size > MAX_BUNDLES) bundles.delete(bundles.keys().next().value!);
            }
            const answer = (await bundle)[targetPath];
            if (answer === undefined) throw notIndexed(targetPath);
            return answer;
        },
        async search(query: string, limit: number) {
            const at = await index();
            searchIndex ??= file<DemoSearchIndex>("search.json").then(buildStaticSearch).catch((err: unknown) => {
                searchIndex = null;
                throw err;
            });
            return searchStatic(await searchIndex, query, { limit, repoName: at.manifest.repo });
        },
        async status() {
            return (await index()).manifest.status;
        },
        async source(): Promise<SourceResponse> {
            throw notInDemo("The source viewer");
        },
        async summarize(): Promise<SummarizeResponse> {
            throw notInDemo("Summarizing");
        },
        async repos(): Promise<RepoList> {
            const m = (await index()).manifest;
```

```ts
function walk(dir: string): { files: number; bytes: number; byTop: Map<string, number> } {
    const byTop = new Map<string, number>();
    let files = 0;
    let bytes = 0;
    for (const entry of fs.readdirSync(dir, { recursive: true, withFileTypes: true })){
        if (!entry.isFile()) continue;
        const size = fs.statSync(path.join(entry.parentPath, entry.name)).size;
        const top = path.relative(dir, entry.parentPath).split(path.sep)[0] || ".";
        files++;
        bytes += size;
        byTop.set(top, (byTop.get(top) ?? 0) + size);
    }
    return { files, bytes, byTop };
}
```

```ts
/**
 * The eval's ground truth for imports (R3 in docs/plans/2026-10-13-v1-5-ship.md): a regex over the source and its own
 * relative-path resolution. It imports nothing from lib/, so the truth never comes from Nebulosity's index. Its false
 * hits (an import inside a string or a block comment) and misses (a non-relative specifier) are found by reading the
 * source in Task 17, never by asking the indexer.
 */
import { execFileSync } from "child_process";
import fs from "fs";
import path from "path";

/** import … from '…', export … from '…', import '…', import('…'), require('…'). */
const SPECIFIER = /(?:\bfrom\s*|\bimport\s*\(\s*|\brequire\s*\(\s*|^\s*import\s+)['"]([^'"\n]+)['"]/gm;
const CODE_FILE = /\.[cm]?[jt]sx?$/;
const EXTENSIONS = [".ts", ".tsx", ".mts", ".cts", ".js", ".jsx", ".mjs", ".cjs"];
/** TypeScript's pairs: a .js specifier names the .ts file next to it once compiled, and so on. */
const COMPILED_FROM: Record<string, string[]> = { ".js": [".ts", ".tsx"], ".jsx": [".tsx"], ".mjs": [".mts"], ".cjs": [".cts"] };

/** The specifiers a file imports, in order. Lines starting with // or * are skipped as comments. */
export function importSpecifiers(text: string): string[] {
    const code = text.split(/\r?\n/).filter((line) => !/^\s*(?:\/\/|\*)/.test(line)).join("\n");
    return [...code.matchAll(SPECIFIER)].map((m) => m[1]);
}

/** A relative specifier as a file the repo has, or null: its TypeScript source, itself, an added extension, or an index file. */
export function resolveRelative(fromFile: string, specifier: string, known: ReadonlySet<string>): string | null {
    if (!specifier.startsWith(".")) return null;
    const base = path.posix.normalize(path.posix.join(path.posix.dirname(fromFile), specifier));
    const ext = path.posix.extname(base);
    const stem = base.slice(0, base.length - ext.length);
    const candidates = [
        ...(COMPILED_FROM[ext] ?? []).map((e) => stem + e),
        ...(CODE_FILE.test(base) ? [base] : []),
        ...EXTENSIONS.map((e) => base + e),
        ...EXTENSIONS.map((e) => `${base}/index${e}`),
    ];
    return candidates.find((c) => known.has(c)) ?? null;
}

export type ScannedGraph = { files: string[]; edges: [string, string][] };

/** Every code file git tracks under root, and every import between them the regex finds and resolves (each pair once). */
export function scanRepo(root: string): ScannedGraph {
    const files = execFileSync("git", ["-C", root, "ls-files", "-z"], { encoding: "utf8", maxBuffer: 256 * 1024 * 1024 })
        .split("\0")
        .filter((f) => CODE_FILE.test(f));
    const known = new Set(files);
    const edges: [string, string][] = [];
    for (const file of files){
        const seen = new Set<string>();
        for (const specifier of importSpecifiers(fs.readFileSync(path.join(root, file), "utf8"))){
            const target = resolveRelative(file, specifier, known);
            if (target !== null && target !== file && !seen.has(target)){
                seen.add(target);
                edges.push([file, target]);
            }
        }
    }
    return { files, edges };
}
```

```ts
/** The eval's truths over a scanned graph (R3): who imports a file or a folder, what depends on a file, the shortest chain. */
export type Graph = { files: readonly string[]; edges: readonly (readonly [string, string])[] };

const sorted = (paths: Iterable<string>): string[] => [...new Set(paths)].sort((a, b) => (a < b ? -1 : a > b ? 1 : 0));
const inside = (p: string, folder: string): boolean => p === folder || p.startsWith(`${folder}/`);

function adjacency(g: Graph, reverse: boolean): Map<string, string[]> {
    const map = new Map<string, string[]>();
    for (const [a, b] of g.edges){
        const [from, to] = reverse ? [b, a] : [a, b];
        map.set(from, [...(map.get(from) ?? []), to]);
    }
    for (const [key, list] of map) map.set(key, sorted(list));
    return map;
}

export const hasEdge = (g: Graph, a: string, b: string): boolean => g.edges.some(([x, y]) => x === a && y === b);
export const directImporters = (g: Graph, target: string): string[] => sorted(g.edges.filter(([, b]) => b === target).map(([a]) => a));
export const outsideImporters = (g: Graph, folder: string): string[] =>
    sorted(g.edges.filter(([a, b]) => inside(b, folder) && !inside(a, folder)).map(([a]) => a));

export function transitiveDependents(g: Graph, target: string): string[] {
    const into = adjacency(g, true);
    const seen = new Set([target]);
    const queue = [target];
    while (queue.length > 0) for (const next of into.get(queue.shift()!) ?? []) if (!seen.has(next)){ seen.add(next); queue.push(next); }
    seen.delete(target);
    return sorted(seen);
}

/** Breadth-first from `from`, neighbours in path order, so the same chain comes back every time; `to` may be a folder. */
export function shortestChain(g: Graph, from: string, to: string): string[] | null {
    const out = adjacency(g, false);
    const previous = new Map<string, string | null>([[from, null]]);
    const queue = [from];
    while (queue.length > 0){
        const at = queue.shift()!;
        if (at !== from && inside(at, to)){
            const chain: string[] = [];
            for (let p: string | null = at; p !== null; p = previous.get(p)!) chain.push(p);
            return chain.reverse();
        }
        for (const next of out.get(at) ?? []) if (!previous.has(next)){ previous.set(next, at); queue.push(next); }
    }
    return null;
}
```

```ts
/** Reading a run's final answer and scoring it against the truth (D2, R4 in docs/plans/2026-10-13-v1-5-ship.md). */
const CODE_FILE = /\.[cm]?[jt]sx?$/;

/** The text after the last line that starts with ANSWER: (any case, markdown around it ignored), or null. */
export function answerSection(text: string): string | null {
    const lines = text.split(/\r?\n/);
    for (let i = lines.length - 1; i >= 0; i--){
        const m = /^[\s>*_#-]*answer\s*:\s*\**\s*(.*)$/i.exec(lines[i]);
        if (m) return [m[1], ...lines.slice(i + 1)].join("\n").trim();
    }
    return null;
}

export const isNone = (section: string): boolean => /^\W*none\b/i.test(section.trim());

/**
 * The repo's files an answer lists, in order, once each, matched without regard to case (the eval runs on Windows):
 * absolute paths inside the repo with either slash, or repo-relative ones, stripped of bullets, numbering, backticks,
 * quotes and a trailing :line or #Lline. Anything path-like that isn't a file of the repo goes to notFiles.
 */
export function extractPaths(section: string, repoRoot: string, known: ReadonlySet<string>): { files: string[]; notFiles: string[] } {
    const root = repoRoot.replace(/\\/g, "/").replace(/\/+$/, "").toLowerCase();
    const canonical = new Map([...known].map((k) => [k.toLowerCase(), k]));
    const files: string[] = [];
    const notFiles: string[] = [];
    for (const token of section.match(/[^\s`'"()[\],;]+/g) ?? []){
        let p = token.replace(/\\/g, "/").replace(/^[-*•>]+/, "").replace(/^\d+[.)]$/, "");
        p = p.replace(/(?::\d+(?::\d+)?|#L\d+(?:-L?\d+)?)$/, "").replace(/[.:]+$/, "");
        if (!p.includes("/") && !CODE_FILE.test(p)) continue;
        if (p.toLowerCase().startsWith(`${root}/`)) p = p.slice(root.length + 1);
        p = p.replace(/^\.\//, "");
        const file = canonical.get(p.toLowerCase());
        if (file !== undefined){
            if (!files.includes(file)) files.push(file);
        } else if (!notFiles.includes(p)) notFiles.push(p);
    }
    return { files, notFiles };
}

export type ListScore = { recall: number; precision: number; hits: number; missed: string[]; extra: string[] };

/** Recall is what the eval scores lists by (PIVOT_SPEC.md §9); precision is reported beside it. */
export function scoreList(found: readonly string[], truth: readonly string[]): ListScore {
    const want = new Set(truth);
    const hits = found.filter((p) => want.has(p));
    return {
        recall: truth.length === 0 ? 1 : hits.length / truth.length,
        precision: found.length === 0 ? 0 : hits.length / found.length,
        hits: hits.length,
        missed: truth.filter((p) => !found.includes(p)),
        extra: found.filter((p) => !want.has(p)),
    };
}

export type ChainTruth = { from: string; to: string; connected: boolean; shortest: number | null };
export type ChainScore = { score: 0 | 0.5 | 1 | null; valid: boolean; steps: number | null; problem?: string; unknown?: [string, string] };

/**
 * 1 for a valid chain of the shortest length or a right "none", 0.5 for a valid longer chain, 0 otherwise (D2). `to`
 * may be a folder. `imports` says whether one file imports another: true, false, or null when nobody knows yet. A null
 * step leaves the score null until it's adjudicated by reading the source (R4).
 */
export function scoreChain(answer: { none: boolean; files: readonly string[] }, truth: ChainTruth, imports: (a: string, b: string) => boolean | null): ChainScore {
    if (!truth.connected){
        return answer.none && answer.files.length === 0
            ? { score: 1, valid: true, steps: null }
            : { score: 0, valid: false, steps: null, problem: "claims a chain where none exists" };
    }
    const f = answer.files;
    if (answer.none || f.length < 2) return { score: 0, valid: false, steps: null, problem: "no chain given" };
    const steps = f.length - 1;
    const reaches = (p: string): boolean => p === truth.to || p.startsWith(`${truth.to}/`);
    if (f[0] !== truth.from || !reaches(f[f.length - 1])) return { score: 0, valid: false, steps, problem: "doesn't run from the first file to the last" };
    for (let i = 0; i < steps; i++){
        const known = imports(f[i], f[i + 1]);
        if (known === null) return { score: null, valid: false, steps, unknown: [f[i], f[i + 1]] };
        if (!known) return { score: 0, valid: false, steps, problem: `${f[i]} doesn't import ${f[i + 1]}` };
    }
    if (truth.shortest !== null && steps < truth.shortest) return { score: 1, valid: true, steps, problem: "shorter than the truth's shortest: recheck the truth" };
    return { score: steps === truth.shortest ? 1 : 0.5, valid: true, steps };
}
```

```ts
    for (const line of jsonl.split(/\r?\n/)){
        try{
            const parsed = JSON.parse(line) as unknown;
            if (parsed !== null && typeof parsed === "object") events.push(parsed as Json);
        } catch{
            // a partial or non-JSON line: skipped
        }
    }
    const init = events.find((e) => e.type === "system" && e.subtype === "init") ?? {};
    const result = [...events].reverse().find((e) => e.type === "result") ?? {};
    const limits = [...events].reverse().find((e) => e.type === "rate_limit_event")?.rate_limit_info?.unifiedWindows ?? {};

    const toolCalls: Record<string, number> = {};

        if (e.type === "user") toolErrors += content.filter((c) => c.type === "tool_result" && c.is_error === true).length;

        [toolCalls, nestedToolCalls].reduce((sum, calls) => sum + Object.entries(calls).filter(([n]) => pick(n)).reduce((s, [, c]) => s + c, 0), 0);
    const usage = result.usage ?? {};

    return {
        model: init.model ?? null, claudeVersion: init.claude_code_version ?? null, apiKeySource: init.apiKeySource ?? null, permissionMode: init.permissionMode ?? null,
        tools: init.tools ?? [],
        mcpServers: (init.mcp_servers ?? []).map((s: Json) => ({ name: s.name, status: s.status })),

        skills: (init.skills ?? []).length,

        turns: result.num_turns ?? 0, durationMs: result.duration_ms ?? 0, apiMs: result.duration_api_ms ?? 0, costUsd: result.total_cost_usd ?? 0,
        usage: { input: usage.input_tokens ?? 0, cacheWrite: usage.cache_creation_input_tokens ?? 0, cacheRead: usage.cache_read_input_tokens ?? 0, output: usage.output_tokens ?? 0 },

        toolCalls, nestedToolCalls, toolErrors,
```

```ts
        "--disallowedTools", DENIED_TOOLS.join(","),
        "--no-session-persistence",

export function childEnv(base: Readonly<Record<string, string | undefined>>, options: { gitBash: string; toolSearch: boolean; configDir?: string }): Record<string, string> {
    const env: Record<string, string> = {};
    for (const [key, value] of Object.entries(base)) if (value !== undefined && !STRIPPED.has(key.toUpperCase())) env[key] = value;
    Object.assign(env, {
        CLAUDE_CODE_GIT_BASH_PATH: options.gitBash,
        CLAUDE_CODE_USE_POWERSHELL_TOOL: "0",

        DISABLE_AUTOUPDATER: "1",
        NEBULOSITY_LIVE: "off",
    });

    if (options.configDir) env.CLAUDE_CONFIG_DIR = options.configDir;

export type RunId = { question: string; arm: Arm; repeat: number; toolSearch: boolean };
export const runName = (r: RunId): string => `${r.question}-${r.arm}${r.toolSearch ? "" : "-upfront"}-${r.repeat}`;

/** Per repeat, question by question, both arms; which arm goes first alternates by question and by repeat, so neither always meets a warmer cache or a later hour. */
export function schedule(questions: readonly string[], repeats: number): RunId[] {
    const runs: RunId[] = [];
    for (let repeat = 1; repeat <= repeats; repeat++){
        questions.forEach((question, i) => {
            const arms: Arm[] = (i + repeat - 1) % 2 === 0 ? ["baseline", "nebulosity"] : ["nebulosity", "baseline"];
            for (const arm of arms) runs.push({ question, arm, repeat, toolSearch: true });
        });
    }
    return runs;
}

/** The paths `git status --porcelain` names: anything there means a run changed the repo. */
export const parsePorcelain = (stdout: string): string[] => stdout.split(/\r?\n/).filter((line) => line.trim() !== "").map((line) => line.slice(3));

const escapeRegExp = (s: string): string => s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");

/** Every spelling (lib/demo/privacy.ts) of each folder replaced, deepest folder first, so a transcript can be published (D7). */
export function scrub(text: string, replacements: readonly { folder: string; with: string }[]): string {
    const ordered = [...replacements].sort((a, b) => b.folder.length - a.folder.length);
    let out = text;
    for (const r of ordered){
        for (const spelling of spellings(r.folder).sort((a, b) => b.length - a.length)){
            out = out.replace(new RegExp(escapeRegExp(spelling), "gi"), r.with);
        }
    }
    return out;
}
```

```ts
/** Each run is checked against D3, not trusted (R13): its init message before it counts, its result for notes. */
import type { Arm } from "./run-config";
import type { RunSummary } from "./transcript";

const REQUIRED_TOOLS = ["Bash", "Read", "Grep", "Glob"];
const FORBIDDEN_TOOLS = ["WebFetch", "WebSearch", "Skill", "PowerShell", "Edit", "Write"];

export function validateInit(run: RunSummary, expect: { arm: Arm; model: string; forbiddenPlugins: readonly string[] }): string[] {
    const problems: string[] = [];
    if (run.model !== expect.model) problems.push(`model is ${run.model}, not ${expect.model}`);
    if (run.permissionMode !== "dontAsk") problems.push(`permission mode is ${run.permissionMode}, not dontAsk`);
    if (run.apiKeySource !== null && run.apiKeySource !== "none") problems.push(`an API key is in use (${run.apiKeySource}), not the subscription`);
    const servers = run.mcpServers.map((s) => `${s.name}:${s.status}`);
    const wanted = expect.arm === "nebulosity" ? ["nebulosity:connected"] : [];
    if (servers.join(",") !== wanted.join(",")) problems.push(`MCP servers are [${servers.join(", ")}], not [${wanted.join(", ")}]`);
    for (const plugin of run.plugins) if (expect.forbiddenPlugins.includes(plugin)) problems.push(`the owner's plugin ${plugin} is loaded`);
    for (const tool of REQUIRED_TOOLS) if (!run.tools.includes(tool)) problems.push(`${tool} is missing`);
    for (const tool of FORBIDDEN_TOOLS) if (run.tools.includes(tool)) problems.push(`${tool} is present`);
    return problems;
}

/** Things to report about a finished run, not to discard it for: another model answering (a fallback), an error ending. */
export function resultNotes(run: RunSummary, allowedModels: readonly string[]): string[] {
    const notes = Object.keys(run.models).filter((m) => !allowedModels.includes(m)).map((m) => `model ${m} also answered (a fallback?)`);
    if (run.subtype !== "success") notes.push(`ended with ${run.subtype}`);
    return notes;
}
```

```markdown
On a big repo, three kinds of question are hard for an agent that searches on demand: **big-picture** (what are the parts, and how do they talk?), **complete-list** (every file that depends on this one) and **repeated** (every new session pays for the same exploration again).
```
