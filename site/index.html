A live map of how a big codebase fits together, for Claude Code and for you.

Nebulosity indexes every import in a repository ahead of time, so Claude Code can answer questions that follow imports through many files with one tool call. In tests, Claude Code with Nebulosity answered them up to 4.4× faster, and up to 3.2× faster on Theia, a codebase Nebulosity was never adjusted for. It got every one of them right.

Install

Needs Node 24 or later, git, and Claude Code 2.1.300 or later.

In your terminal

  1. Install the package

    • npm install -g nebulosity

  2. In your repo's root folder

    • nebulosity index .
      reads the repo, free
    • nebulosity map
      opens the Map, keeps running
    • nebulosity setup
      in a new terminal: connects Claude Code

nebulosity doctor says what's missing, and the guide has every command.

In VS Code

  1. Install the package and index your repo

  2. Install the Nebulosity extension

    • code --install-extension andrewl746.nebulosity-vscode

  3. Run Nebulosity: Show Map from the Command Palette

Then ask Claude Code

  • What could break if src/vs/base/common/event.ts changes?
  • How does main.ts end up loading terminal.ts?
  • Which entry points load this file?
  • Are there import cycles in src/vs/platform?
