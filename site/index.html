A live map of your codebase, for you and Claude Code.

Nebulosity indexes every import in your repo, so Claude Code can answer questions that span many files in one call. In tests, that made it up to 4.4× faster, and up to 3.2× faster on Theia, a codebase Nebulosity was never adjusted for. Every answer was right.

Try the live demo View on GitHub

Free and open source. Without an API key, none of your code leaves your machine.

See the same imports on the Map

One folder at a time, with lines for what imports what. Click any box to see what it uses and what uses it, or press Ctrl K to search.

Tested against Claude Code on its own

The same questions, with and without Nebulosity, on three large TypeScript codebases: 378 runs, each checked against a reference answer.

Install

You'll need
  • Node 24 or later
  • git
  • Claude Code 2.1.300 or later

In your terminal

4 steps
  1. 1

    Install the package

    npm install -g nebulosity
  2. 2

    Index your repo

    From its root folder. Free.

    nebulosity index .
  3. 3

    Open the Map

    It keeps running, at localhost:3000.

    nebulosity map
  4. 4

    Connect Claude Code

    In a second terminal, same folder.

    nebulosity setup

If something seems off, nebulosity doctor says what's missing. Every command is in the guide.

In VS Code

2 steps, after the first two above
  1. 1

    Install the extension

    From the Marketplace, or in a terminal.

    code --install-extension andrewl746.nebulosity-vscode
  2. 2

    Open the Map

    It follows the file you have open.

    Command PaletteNebulosity: Show Map

Then ask Claude Code

4 examples
  • What could break if src/vs/base/common/event.ts changes?
  • How does main.ts end up loading terminal.ts?
  • Which entry points load this file?
  • Are there import cycles in src/vs/platform?

Seven languages

TypeScript, JavaScript, Python, Go, Java, C# and Rust.

AI summaries, optional

With an Anthropic API key, a summary of every file and folder for about $1 per 1,000 files. It sends your code to Anthropic, and asks before spending.
